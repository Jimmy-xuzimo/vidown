# Vidown 使用指南

适用于 Windows x64 1.0.2。已验证内容和限制见 [测试记录](VALIDATION.md)。

## 开始使用

正常退出旧版后运行新版，推荐日常使用安装版。系统需有 Evergreen WebView2 Runtime，无需另装 Python、Node.js、.NET 或 FFmpeg。账号与任务保存在当前 Windows 用户的应用资料目录；免安装包不会把完整账号资料随 EXE 搬迁。

先在「设置与账号」选择保存目录和代理。软件默认使用系统代理，也可设置手动代理；浏览器与协议传输使用一致策略。界面固定紧凑，可切换系统／深色／浅色模式及四套主题，关闭轻量过渡。软件不含鼠标微光。

## 登录与发现

1. 打开「浏览器探测」，新建标签并输入网址；没有协议时会补全。标签高度固定，长标题末尾省略。
2. 在网页中登录自己的账号，再播放目标视频。网站 Cookie 和站点存储保存在本机；升级到 WebView2 后旧浏览器完整站点存储不能自动迁移，可能需要重新登录一次。
3. 点击「提取当前页面」，或解析侧栏中发现的 HLS／DASH 资源；也可以回工作台粘贴同一页面链接并重新探测。
4. 从源实际提供的列表分别选择视频与音频。没有提供的规格不会凭标题补出。网页预览能力与下载轨道能力分别判断。

临时会话 Cookie 在系统安全存储可用时加密保留最多 7 天，持久 Cookie 遵循原有效期。网站仍可能要求重新验证。没有 Chrome／Edge 数据库导入、cookies.txt 导入或配套扩展。「清除内置浏览器登录」会删除该应用内的登录数据和备份。

网页提供的文件保存操作也可以进入任务；blob 需要原网页上下文，不能当作普通直链。网页无保存权限时会停止；若网页要求额外选择档位，请在网页菜单中选择。真实私有消息和所有站点的账号兼容性尚未全部验收。

## 保存与输出

默认保留源编码并无损合并；适合的组合使用 MP4，部分高规格组合使用 MKV。选择纯音频时取消视频轨道并选音轨，原始 FLAC 保存为 FLAC。Hi-Res 与多声道音轨属于不同选择。

兼容导出可能有损；本版本拒绝没有明确色彩转换策略的 HDR／杜比兼容导出。分辨率、动态范围、音频采样率与位深按实际源分别判断。

下载、合并和成品验证是不同阶段。只有验证通过才标记完成。失败时查看具体错误，并可从设置导出脱敏诊断；诊断不包含密码、Cookie 正文或完整签名链接。

## 队列与记录

同次运行中可暂停和继续；暂停会停止实际传输，继续前检查源身份。取消和完成的任务不能原地重新排队。退出会停止下载组件；重启后记录保留，但需重新探测并新建任务，不自动恢复旧授权。

下载记录支持搜索、单条删除与一键清理。默认只删除记录；勾选同步删除时，将对应成品移至回收站。进行中与暂停任务受到保护。

复制链接可自动填入工作台，不会自动访问或下载；此功能可在设置中关闭。账号权限、试看、地域、风控与 DRM 仍可能限制下载；软件不提供绕过功能。
