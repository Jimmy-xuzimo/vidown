## M0 技术边界

- 内部对象分为 SourceCandidate、RequestContextRef、MediaAsset、DownloadPlan 和 TaskEvent；前端只拿脱敏后的媒体参数。
- 各站登录均在同一持久浏览器分区中按源隔离保存。媒体执行在独立 Electron utility process 中运行。
- 浏览器请求使用任务专属传输桥，只有登记的资源可访问；重定向重新按目标地址选择请求头。
- 任务及状态存 SQLite；敏感计划仅在系统安全存储可用时加密保存。当前版本不会直接重用重启前的授权上下文。
- 暂停终止实际传输及组件进程树，恢复需验证清单指纹或直链强 ETag；不将分片引擎的退出码直接当作媒体成功。
- 常规成品检查覆盖轨道参数、时长和首帧元数据；B 站真实样本额外完成完整码流哈希检查。两者都不等于支持杜比的硬件播放验收。

alpha.6 增加 Windows 系统 WebView2 宿主、统一剪贴板自动填入、固定紧凑密度和双安装形态。此前真实平台结果不自动扩展为新浏览器后端已完成账号验收；仍需在用户重新登录后复验。完整旧 Chromium 网站存储不自动迁移，旧档案保留。
