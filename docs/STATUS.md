# 当前状态

当前版本为 **1.0.3**。Actions 新增 Windows x64、macOS Intel／Apple Silicon、Linux x64／ARM64 原生打包、受控下载验证及统一 Release 附件发布；源码与构建材料随包提供。运行结果见 Release 附件中的分平台 verification 报告。

外部浏览器 Cookie 导入与配套导出扩展已移除；统一使用内置浏览器登录和本机会话保存。Windows 网页使用 WebView2，其他系统使用 Chromium。

完整能力边界以 [README](../README.md)、[测试记录](VALIDATION.md)、[多平台构建](BUILDING.md) 和 [路线图](ROADMAP.md) 为准。CI 桌面启动和真实受控下载不代替干净系统安装／卸载、真实会员／私有账号、全部 Linux 发行版或人工 HDR 播放验收。
