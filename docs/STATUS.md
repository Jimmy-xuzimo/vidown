## 之前版本的媒体验证

以下真实平台结果来自此前 Chromium 版本，不等同于 WebView2 新后端已经完成真实账号复验。

已完成的新验证：

- B 站 4K 杜比视界＋Atmos、8K SDR＋AAC、独立 4K HDR10＋AAC：实际下载及无损合并，完整视频／音频编码码流哈希一致。8K 与 HDR10 是独立选择。
- B 站备用 CDN：主动阻断主源后，完整杜比音轨从备用源下载；跨源不拼接旧字节。
- X：公开链接可以实际下载；按用户要求取消四小时长视频，9 秒音视频样本合并及解码通过。未标记完整长视频成功。
- 独立公开 X 短视频：约 3.18 秒、720p＋AAC，完整桌面下载、全片解码及完整音视频码流哈希通过。
- B 站真实 FLAC：48 kHz／24-bit 双声道，完整视频＋FLAC 无损 MKV、独立纯 FLAC 下载均通过，音频码流哈希保持一致。
- HLS 时间戳切换、同配置连续 DASH 多 Period：实际引擎下载、时长与解码通过。多 Period 最初只保存半段的问题已修复。
- 分片接收量与速度、30 秒停滞超时、正常关闭时停止子进程、重启显示中断任务。
- 数据库原子迁移、任务状态约束、阶段事件顺序和重启提示；实际暂停／恢复／排队取消检查通过。
- 浏览器区域随窗口伸缩；提供 25%–200% 网页缩放、适应宽度及资源栏收起，网站缩放偏好重启保留。受控引擎、桌面与便携包验证另见各份报告。
- Cookie 持久化：持久 Cookie 遵循网站有效期，临时会话 Cookie 使用系统安全存储加密备份最多 7 天；清除登录同时清除备份。重启后不打开登录页，下载工作台使用相同会话完成受保护 HLS 下载。
- 真实 B 站工作台：应用重启、未打开浏览器标签页，直接粘贴 BV1NGZtBwELa，列出 4K 杜比视界和杜比音轨，默认选择 2160p。此前完整高规格下载验证仍有效，本轮未重复下载整片。
- 29 项单元／本地集成检查通过；浏览器／会话专项 4 项（此前会话实现未变）、网页保存专项 14 项、打包桌面 5 项及正常关闭测试通过，见 [验证记录](VALIDATION.md)。
- 统一浏览器登录和链接解析入口；移除 Telegram API 表单、TDLib 工作进程和依赖。Telegram Web A／K DOM／blob 保存链路通过受控测试；修复 webk.telegram.org 的站内播放地址被当普通直链请求而出现 502 的路由错误，真实账号完整下载尚未验收。
