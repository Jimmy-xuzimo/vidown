# Windows 预览版试用

当前是 M0 实验预览。已验证的规格和限制以 [验证记录](VALIDATION.md) 为准；[检查点](STATUS.md) 列出本轮结果。

## 启动与保存位置

双击 `release/Vidown Preview 1.0.0-alpha.1.exe`。便携 EXE 自带浏览器和下载工具，首次启动会自解压；无需安装 Python、Node.js 或 FFmpeg。包目前未签名，文件 SHA-256 与运行时代码版本见 [构建记录](validation/windows-preview-artifact.json)。

先在「设置与账号」选择保存目录。浏览器登录和任务数据库按当前 Windows 用户保存，不随 EXE 自动搬迁；开发验收使用的隔离登录档案也不会自动导入普通启动的应用。

## 下载 B 站高规格内容

1. 在「浏览器探测」输入视频页面，登录自己的账号并播放。需要大会员的规格以账号实际返回的格式为准。
2. 点击「提取当前页面」，回到「选择保存规格」。登录前已提取过的结果需要重新探测。
3. 在「视频轨道」分别查看分辨率、编码、帧率、HDR10 或杜比视界；在「音频轨道」选择 AAC、FLAC 或杜比音轨。Hi-Res 和杜比多声道是不同选择。没有返回的规格不会凭标题补出。
4. 使用默认保留源规格的输出策略，点击「加入下载队列」。完成后在「下载记录」打开文件位置。

杜比视界和视频＋FLAC 组合使用 MKV。8K SDR 与 4K HDR10 可以是同一视频中的不同轨道；选择 8K 不代表同时得到 HDR。浏览器预览、显示器能力与下载保存的源规格分别判断。

单独保存音乐时，将「视频轨道」设为「仅下载音频」，再选择音轨；原始 FLAC 会输出 `.flac`。本版拒绝未经明确色彩转换的 HDR／杜比兼容导出。

## X 和通用流媒体

公开 X 帖子可先在下载工作台粘贴链接并点击「探测资源」。需要登录的页面可在内置浏览器打开；本轮仅验证了公开 X 内容，登录 X 仍待验收。

通用网站在浏览器内登录并播放后，从资源侧栏优先解析 HLS／DASH 清单，再选择视频和音频。`blob:` 本身不是下载地址，需要等待其背后的实际媒体请求。资源侧栏无结果或提取失败时，保留错误信息，在「设置与账号」导出脱敏诊断。

## 暂停、恢复与错误

同一次应用会话中的暂停会停止实际传输；继续时验证清单或源文件身份。正常退出会停止下载组件。重启后的任务保留记录，但需要重新粘贴链接探测并新建任务；此版本不自动恢复过期授权。取消和完成的任务不能原地重新入队。

“正在下载”“合并轨道”“验证成品”是不同阶段，未验证通过不会标记完成。页面可播放但提取失败时，检查具体错误及账号实际权限；DRM、试看、源未提供目标规格与网络失败需要分别判断。可以保留错误和下载记录，稍后再处理需要账号或样本的项目。

Telegram 已有本地 TDLib 接入与登录界面，仍需要 Vidown 自有 API 应用身份及真实私有消息验收。Chrome／Edge 扩展、自动刷新签名和正式跨平台安装包仍在路线图中。
