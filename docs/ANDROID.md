# Android 安装与使用

当前为 **0.1.0-preview.5 签名预览版**，独立于桌面版 1.0.5。应用使用 Kotlin、Jetpack Compose 和 Material 3 编写，网页使用 GeckoView；不运行 Electron、React 或桌面原生宿主。尚未命名稳定版，也未上架 Google Play。

## 安装与升级

从 [Android Release](https://github.com/Jimmy-xuzimo/vidown/releases/tag/android-v0.1.0-preview.5) 下载唯一的 `Vidown-Android-0.1.0-preview.5.apk`。要求 Android 14+（API 34），同一 APK 包含 ARM64 与 x86_64，面向手机、平板及可调整大小的窗口。首版不承诺 Chromebook 或 Windows 安卓环境。

在系统提示时仅授权用于安装此 APK 的应用。浏览器、Python、提取器、JavaScript 引擎与媒体库均随包提供，无需另外安装运行时；这也使 APK 较大，约 432 MiB。相同签名可覆盖升级，卸载会丢失应用私有资料。Android 与桌面版不自动同步账号、设置或下载记录。

应用源码由同版本标签提供。[独立资料页](https://github.com/Jimmy-xuzimo/vidown/releases/tag/android-materials-v0.1.0-preview.5) 保存完整源码／第三方构建材料和 SHA-256；AAB 用于后续 Play 评估，不作为普通用户安装包。

## 从链接到成品

1. 在工作台顶部粘贴媒体页面链接，也可通过 Android 系统分享菜单发送链接；分享文字中包含 URL 也可识别。多条链接每行一条。
2. 点击解析。需要账号时进入统一的浏览器入口登录、播放，再回到工作台解析，或选择浏览器资源。网页默认使用桌面 User-Agent 和视口，可按标签切换移动模式。
3. 展开解析结果，分别选择视频和音频。列表显示源实际返回的分辨率、编码、动态范围、码率等；未提供的值不会推算成“最高”。若只有包含音频的合轨来源，不能再叠加第二条音频。可选择仅保存音频。
4. 加入队列，在通知或应用中查看下载、合并和检查进度。默认优先保留源编码；通过检查并成功保存后才显示完成。
5. 默认保存到系统媒体存储；自定义文件夹使用系统目录选择器授权。下载记录可单条删除或清空，是否同步删除文件需另外选择。系统媒体回收站和自定义目录删除的行为不同，以确认提示为准。

浏览器与链接解析共用 Gecko 会话。持久 Cookie 按网站有效期保存；临时 Cookie 加密恢复窗口最多七天，网站仍可提前使会话失效。不支持外部浏览器 Cookie 导入。网站禁止嵌入式登录时会提示原因；系统浏览器登录不会自动回流应用。

## 界面、后台与数据

- 竖屏导航悬浮在底部居中；横屏在左侧居中，按当前窗口调整。手机资源列表使用原生面板，宽窗口可并排显示网页与资源。
- 设置保留四套配色、系统／浅色／深色、可关闭的动效、代理、并发 1–4 和限速。无持续运行的装饰动画。剪贴板辅助默认关闭，仅在应用获得焦点时检查，不覆盖正在编辑的链接，也不自动访问或下载。
- Android 14+ 由用户主动数据传输任务（UIDT）执行下载，WorkManager 管理后处理。系统仍可能因配额、电量或进程停止而中断任务；不承诺无限后台运行。仅在同次运行且源身份可确认时恢复，重启后须重新解析并新建任务。
- 清除浏览器数据会关闭标签，清除 Cookie、站点存储、缓存、历史和登录备份，并使旧资源授权失效；清理下载记录默认保留成品。有活动任务时按界面提示先结束任务。
- 不申请管理所有文件、无障碍或后台剪贴板权限。API 37 的局域网媒体需系统额外授权；正常互联网访问不依赖此授权。

## 已验证与仍需验证

受控样本验证了 HTTP、HLS TS／fMP4／字节范围／普通 AES-128／密钥轮换／独立音轨、DASH 分轨、暂停取消、源变化、备用 CDN、跨域凭据隔离、无损合并和系统存储发布。浏览器的 blob 保存、同会话登录及清理失效也属于受控测试范围。

公开 B 站样本无需账号时返回 12 个视频与 3 个音频格式；签名 APK 在模拟器完成一个 1080p HEVC＋AAC、约 218.56 秒的成品下载。它不证明会员 4K／8K／HDR／杜比视界或 Hi-Res 权限已经验收。桌面版的真实会员测试不能移作 Android 证据。

模拟器覆盖 API 34—37 的手机和平板及 API 37.2 的 16KB 页面环境；安装包同时包含 ARM64，但当前执行证据来自 x86_64。真实账号、ARM64 真机、折叠姿态、后台策略、续航、温控、HDR 显示及全部站点仍有待验证项。历史通过记录与后续失败／修复分开保留，当前范围见 [Android 验收记录](../android/ACCEPTANCE.md)和[证据索引](../android/verification/index.json)。

不提供直播录制、频道／合集批量抓取、TDLib、DRM 或账号权限绕过，不读取网页客户端内部会话密钥。兼容导出不会在没有明确色彩策略时悄悄把 HDR／杜比视界转为 SDR。
