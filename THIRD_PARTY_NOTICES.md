Installed npm components retain their license files. The Windows application directory retains Electron's LICENSE and LICENSES.chromium.html. Tool preparation copies the FFmpeg distribution's license text into the tool directory and records exact binary SHA-256 values and build identifiers.

The local M0 preview is not a public release. Before public binary publication, the release gate requires complete corresponding-source availability for bundled copyleft builds, component build configuration and source revisions, native-library notices, and platform signing / reproducibility checks. A link to an unrelated current source tree does not satisfy that gate. The application must not describe the entire binary bundle as MIT.
