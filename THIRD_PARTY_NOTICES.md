Installed npm components retain their license files. The Windows application directory retains Electron's LICENSE and LICENSES.chromium.html. Tool preparation copies the FFmpeg distribution's license text into the tool directory and records exact binary SHA-256 values and build identifiers.

The Windows webpage host uses the user's installed Microsoft Evergreen WebView2 runtime; that browser runtime is not bundled. Electron remains the local application shell and network transport for protocol downloads. The native host is self-contained, so users do not need a separate .NET installation. Its pinned runtime versions and associated notices are retained in `webview2-host`.

The bundled Windows packages are local verification artifacts. Source-code publication does not publish these binaries. Before public binary publication, the release gate requires complete corresponding-source availability for bundled copyleft builds, component build configuration and source revisions, native-library notices, and platform signing / reproducibility checks. A link to an unrelated current source tree does not satisfy that gate. The application must not describe the entire binary bundle as MIT.
